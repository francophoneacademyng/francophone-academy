# Roadmap de production

## Objectif

Livrer une version professionnelle, accessible et prête pour le déploiement de Francophone Academy.

## Priorités

1. Stabiliser le frontend avec une landing page professionnelle.
2. Créer un design system partagé.
3. Améliorer le SEO et l'accessibilité.
4. Vérifier les règles Firestore et la configuration Firebase.
5. Consolider les workflows de paiement et d'IA.
6. Ajouter une documentation de déploiement.

## Phases

- Phase 0 : Audit du projet et nettoyage initial.
- Phase 1 : Nettoyage des fichiers obsolètes.
- Phase 2 : Landing page et SEO.
- Phase 3 : Design system et refactorisation CSS.
- Phase 4 : Harmonisation des pages existantes.
- Phase 5 : JS partagé, ES Modules, utilitaires.
- Phase 6 : Support responsive multi-écrans.
- Phase 7 : Améliorations SEO, sitemap et metadata.
- Phase 8 : Performance et optimisation.
- Phase 9 : Accessibilité WCAG AA.
- Phase 10 : Vérification Firebase Hosting / Firestore / Functions.
- Phase 11 : Audit Cloud Functions.
- Phase 12 : Audit Paystack.
- Phase 13 : Audit IA Tutor.
- Phase 14 : Tests et emulation.
- Phase 15 : Git commits structurés.
- Phase 16 : Documentation finale.
- Phase 17 : Validation finale.

## Livrables

- `index.html` de landing page.
- `assets/css/design-system.css`, `layout.css`, `components.css`, `landing.css`.
- Documentation `docs/*.md`.
- Nettoyage des anciens fichiers.
- Amélioration des routes et du SEO.
